This community build brings **Archipelago + Anchor together on 2Ship2Harkinian 5.1.0**, assembled and maintained by **ThyHeroOfTime**.

The goal is to make both multiplayer systems accessible from one build, with dedicated controls under **Network → Anchor / Archipelago**.

### Included
- Anchor co-op integration
- Archipelago multiworld integration
- Export of shared randomizer settings as YAML
- Death Link toggle and message scaling
- Connection indicator with color, visibility, and scale controls

### Current status
Compilation and focused checks have passed. Full multiplayer and progression validation remain pending, and some Archipelago locations and options are still unsupported. Please read the included compatibility notes before generating a session.

This is an unofficial community build. No Nintendo ROM or extracted game data is included; players must provide their own supported game copy.
